# Hurricane Intensity Analysis

Are hurricanes getting more intense and shifting course?

## Questions
1. Has the average peak wind speed of Atlantic storms changed since 1950?
2. Are storms making landfall in different places than in past decades?
3. How can a custom "storm severity index" summarize each storm?

## Data
- Source: NOAA hurricane data in Google BigQuery public datasets (`bigquery-public-data`)

## Tools
SQL (BigQuery) · Tableau · Python (pandas, Plotly, Streamlit)

## Repository structure
- `sql/` BigQuery queries
- `tableau/` dashboard screenshots and link
- `python/` notebooks and Streamlit app
- `data/` raw and processed data (small files only)
